Pengaturan Konfigurasi Firebase

Masukkan API Keys proyek Firebase Anda (Firebase Console -> Project Settings)

📌 Panduan Singkat Firebase: 1. Buka Firebase Console lalu buat Proyek Baru.
2. Aktifkan Authentication (Metode Login: Email/Password). Buat akun admin baru di tab Users.
3. Aktifkan Firestore Database (Pilih Start in Test Mode).
4. Salin firebaseConfig dari Web App settings ke form di bawah ini lalu klik Simpan!
