========================================================================
PETUNJUK MUSIK LATAR BELAKANG (BACKGROUND MUSIC)
========================================================================

Simpan file musik Anda di folder ini dengan nama file:
bg-music.mp3

Format yang didukung: .mp3, .ogg, .wav
Lokasi file: assets/audio/bg-music.mp3

Website akan secara otomatis memutar lagu dari file ini pada saat 
halaman dimuat (loading screen) dan menampilkan widget kontrol lagu 
di sudut kanan bawah layar.
